## 1. Общие положения

### 1.1. Назначение

Настоящий документ устанавливает минимальный набор тестов для проверки соответствия данных профилю интероперабельности ЭКБ/РЭА.

### 1.2. Область применения

Тесты применяются при:
- Приёмке данных от участников кооперации
- Внутреннем контроле качества данных
- Сертификации профилей интероперабельности
- Интеграции PLM-систем

### 1.3. Критерии прохождения

| Уровень | Минимальная степень | Допустимые ошибки | Статус |
|---------|---------------------|-------------------|--------|
| A | 0.50 | 0 критичных | Принято |
| B | 0.75 | 0 критичных, ≤3 предупреждения | Принято |
| C | 0.95 | 0 критичных, 0 предупреждений | Принято |

## 6. Приложения

### Приложение A. Автоматизация тестов

```bash
#!/bin/bash
# conformance_test.sh

PROFILE_FILE=$1
LEVEL=${2:-A}

echo "=== Тестирование профиля: $PROFILE_FILE ==="
echo "Уровень: $LEVEL"

# Тест A-1: XSD валидация
echo "[A-1] XSD валидация..."
xmllint --schema xsd/profile/eskd_profile_ekb.xsd $PROFILE_FILE --noout
if [ $? -eq 0 ]; then
    echo "✓ PASS"
else
    echo "✗ FAIL"
    exit 1
fi

# Тест A-2: Обязательные атрибуты
echo "[A-2] Обязательные атрибуты..."
# XPath проверка обязательных элементов

# Тест B-2: Schematron
echo "[B-2] Правила Schematron..."
java -jar saxon-he.jar -s:$PROFILE_FILE -xsl:schematron/eskb-rerea-1.0.sch

echo "=== Тестирование завершено ==="
```
