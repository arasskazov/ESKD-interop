## 1. Общие положения

### 1.1. Назначение

Настоящий документ устанавливает методику расчёта и критерии оценки степени интероперабельности при обмене перечнями разрешённых радиоэлектронной аппаратуры (РЭА) и электронной компонентной базы (ЭКБ).

### 1.2. Область применения

Методика применяется при:
- Оценке соответствия данных профилю интероперабельности
- Определении уровня готовности данных к обмену между системами
- Контроле качества данных при интеграции PLM-систем
- Сертификации профилей интероперабельности

### 1.3. Нормативные ссылки

| Обозначение | Наименование |
|-------------|--------------|
| ГОСТ Р 77.403-202X | Система поддержки жизненного цикла изделия. Профили интероперабельности |
| ГОСТ Р 2.525-2024 | Электронная структура изделия конструктивная. Формат данных |
| ГОСТ Р 2.058-2023 | Реквизитная часть электронных конструкторских документов |
| ГОСТ Р 77.302-202X | Информационная модель изделия. Общие данные об изделии |

### 1.4. Термины и определения

| Термин | Определение |
|--------|-------------|
| **Степень интероперабельности** | Количественная мера покрытия требований профиля интероперабельности (0.00 - 1.00) |
| **Уровень соответствия** | Категоризированная оценка степени интероперабельности (A, B, C) |
| **Обязательный атрибут** | Атрибут, наличие и заполнение которого требуется для минимального соответствия профилю |
| **Рекомендуемый атрибут** | Атрибут, заполнение которого рекомендуется для расширенного соответствия профилю |

## 2. Уровни соответствия

### 2.1. Классификация уровней

| Уровень | Название | Минимальная степень | Статус обмена |
|---------|----------|---------------------|---------------|
| **A** | Базовый | 0.50 | Допустим для внутреннего обмена |
| **B** | Расширенный | 0.75 | Допустим для межорганизационного обмена |
| **C** | Полный | 0.95 | Рекомендуется для критичных данных |

### 2.2. Критерии уровня A (Базовый)

| № | Критерий | Требование |
|---|----------|------------|
| A1 | Валидация XSD | 0 ошибок валидации схемы |
| A2 | Обязательные атрибуты | 100% обязательных атрибутов заполнены |
| A3 | Ссылочная целостность | Все внутренние ссылки валидны |
| A4 | Формат данных | Соответствие формату XML 1.0 |

### 2.3. Критерии уровня B (Расширенный)

| № | Критерий | Требование |
|---|----------|------------|
| B1 | Все критерии уровня A | Выполнены |
| B2 | Рекомендуемые атрибуты | ≥70% рекомендуемых атрибутов заполнены |
| B3 | Правила Schematron | ≥80% правил Schematron пройдено |
| B4 | Маппинг 2.525 ↔ 2.058 | Все критичные связи валидны |

### 2.4. Критерии уровня C (Полный)

| № | Критерий | Требование |
|---|----------|------------|
| C1 | Все критерии уровня B | Выполнены |
| C2 | Рекомендуемые атрибуты | ≥90% рекомендуемых атрибутов заполнены |
| C3 | Правила Schematron | 100% правил Schematron пройдено |
| C4 | Маппинг 2.525 ↔ 2.058 | 100% связей валидны |
| C5 | Дополнительные проверки | Все бизнес-правила соблюдены |

## 3. Методика расчёта степени интероперабельности

### 3.1. Формула расчёта

```
Степень интероперабельности (I) = (M × 0.5) + (R × 0.3) + (S × 0.2)

Где:
  M — доля заполненных обязательных атрибутов (0.0 - 1.0)
  R — доля заполненных рекомендуемых атрибутов (0.0 - 1.0)
  S — доля пройденных правил Schematron (0.0 - 1.0)
```

### 3.2. Расчёт компонентов

#### 3.2.1. Обязательные атрибуты (M)

```
M = M_filled / M_total

Где:
  M_filled — количество заполненных обязательных атрибутов
  M_total — общее количество обязательных атрибутов
```

#### 3.2.2. Рекомендуемые атрибуты (R)

```
R = R_filled / R_total

Где:
  R_filled — количество заполненных рекомендуемых атрибутов
  R_total — общее количество рекомендуемых атрибутов
```

#### 3.2.3. Правила Schematron (S)

```
S = S_passed / S_total

Где:
  S_passed — количество пройденных правил Schematron
  S_total — общее количество правил Schematron
```

### 3.3. Взвешивание компонентов

| Компонент | Вес | Обоснование |
|-----------|-----|-------------|
| Обязательные атрибуты (M) | 0.5 | Критично для базовой интероперабельности |
| Рекомендуемые атрибуты (R) | 0.3 | Важно для расширенной интероперабельности |
| Правила Schematron (S) | 0.2 | Дополнительно для проверки бизнес-правил |

## 5. Примеры расчёта

### 5.1. Пример 1: Уровень A (Базовый)

| Параметр | Значение |
|----------|----------|
| Обязательные атрибуты (заполнено/всего) | 12/12 = 1.00 |
| Рекомендуемые атрибуты (заполнено/всего) | 2/9 = 0.22 |
| Правила Schematron (пройдено/всего) | 5/8 = 0.63 |
| **Расчёт** | **(1.00 × 0.5) + (0.22 × 0.3) + (0.63 × 0.2) = 0.69** |
| **Уровень** | **A (Базовый)** |
| **Статус обмена** | **Допустим для внутреннего обмена** |

|----------|----------|

| Рекомендуемые атрибуты (заполнено/всего) | 7/9 = 0.78 |
| Правила Schematron (пройдено/всего) | 7/8 = 0.88 |
| **Расчёт** | **(1.00 × 0.5) + (0.78 × 0.3) + (0.88 × 0.2) = 0.91** |
| **Уровень** | **B (Расширенный)** |
| **Статус обмена** | **Допустим для межорганизационного обмена** |

## 6. Протокол оценки соответствия

### 6.1. Форма протокола

```
ПРОТОКОЛ ОЦЕНКИ СООТВЕТСТВИЯ ПРОФИЛЮ ИНТЕРОПЕРАБЕЛЬНОСТИ

Идентификатор протокола: {PROFILE}-{YYYY}-{NNN}
Дата проведения: YYYY-MM-DD
Профиль: {profileId}
Версия профиля: {profileVersion}

1. ОБЪЕКТ ОЦЕНКИ
   Файл данных: {fileName}
   Размер файла: {fileSize}
   Источник данных: {sourceSystem}

2. РЕЗУЛЬТАТЫ ВАЛИДАЦИИ
   XSD валидация: {PASS/FAIL}
   Обязательные атрибуты: {M_filled}/{M_total} ({M}%)
   Рекомендуемые атрибуты: {R_filled}/{R_total} ({R}%)
   Правила Schematron: {S_passed}/{S_total} ({S}%)

3. СТЕПЕНЬ ИНТЕРОПЕРАБЕЛЬНОСТИ
   Рассчитанное значение: {I}
   Уровень соответствия: {A/B/C}
   Статус обмена: {внутренний/межорганизационный/критичный}

4. ВЫЯВЛЕННЫЕ НЕСООТВЕТСТВИЯ
   {Перечень ошибок и предупреждений}

5. РЕКОМЕНДАЦИИ
   {Рекомендации по улучшению степени интероперабельности}

6. ПОДПИСИ
   Оценку выполнил: {ФИО}
   Организация: {Наименование}
   Дата: {YYYY-MM-DD}
```

### 6.2. Критерии приёмки

| Уровень | Минимальная степень | Допустимые ошибки | Статус |
|---------|---------------------|-------------------|--------|
| A | 0.50 | 0 критичных | Принято |
| B | 0.75 | 0 критичных, ≤3 предупреждения | Принято |
| C | 0.95 | 0 критичных, 0 предупреждений | Принято |
| Любой | < 0.50 | Любые | Отклонено |

### 6.3. Периодичность оценки

| Ситуация | Периодичность |
|----------|---------------|
| Первоначальная оценка | При первом обмене данными |
| Плановая оценка | 1 раз в квартал |
| Внеплановая оценка | При изменении профиля или структуры данных |
| После исправлений | После устранения выявленных несоответствий |
