## 1. Назначение и область применения

### 1.1. Назначение

Настоящий документ устанавливает требования к профилю интероперабельности для обмена перечнями разрешённых радиоэлектронной аппаратуры (РЭА) и электронной компонентной базы (ЭКБ) между информационными системами участников кооперации.

### 1.2. Область применения

Профиль применяется при:
- Обмене данными о разрешённых перечнях ЭКБ/РЭА между организациями
- Проверке соответствия изделий разрешённым перечням
- Управлении допустимыми заменами компонентов
- Интеграции данных между системами управления конструкторскими данными

### 1.3. Уровни интероперабельности

Профиль обеспечивает два уровня интероперабельности (ГОСТ Р 77.403):

| Уровень | Описание | Реализация |
|---------|----------|------------|
| **Семантический** | Единая модель данных перечней ЭКБ/РЭА | XSD-схема профиля, словари, классификаторы |
| **Технический** | Форматы обмена данными | XML + XSD 1.1, Schematron |

**Примечание:** Организационный уровень интероперабельности не входит в область применения данного профиля и регулируется отдельными соглашениями между участниками обмена.

## 6. Степени интероперабельности

### 6.1. Уровни соответствия

| Уровень | Название | Критерии | Минимальная степень |
|---------|----------|----------|---------------------|
| **A** | Базовый | • Валидация XSD пройдена<br>• Все обязательные атрибуты заполнены | 0.50 |
| **B** | Расширенный | • Уровень A пройден<br>• ≥70% рекомендуемых атрибутов заполнено<br>• Schematron валидация пройдена | 0.75 |
| **C** | Полный | • Уровень B пройден<br>• ≥90% рекомендуемых атрибутов заполнено<br>• Все Schematron правила пройдены<br>• Маппинг 2.525 ↔ 2.058 валиден | 0.95 |

### 6.2. Формула расчёта

```
Степень = (M_filled / M_total) × 0.5 + (R_filled / R_total) × 0.3 + (S_passed / S_total) × 0.2

Где:
  M_filled — заполненные обязательные атрибуты
  M_total — всего обязательных атрибутов
  R_filled — заполненные рекомендуемые атрибуты
  R_total — всего рекомендуемых атрибутов
  S_passed — пройденные правила Schematron
  S_total — всего правил Schematron
```

### 6.3. Пример расчёта

| Параметр | Значение |
|----------|----------|
| Обязательные атрибуты (заполнено/всего) | 7/7 = 1.00 |
| Рекомендуемые атрибуты (заполнено/всего) | 4/6 = 0.67 |
| Правила Schematron (пройдено/всего) | 10/12 = 0.83 |
| **Степень интероперабельности** | **(1.00 × 0.5) + (0.67 × 0.3) + (0.83 × 0.2) = 0.87** |
| **Уровень** | **B (Расширенный)** |

## 7. Правила расширения профиля

### 7.1. Принцип неизменности ядра

Ядро профиля (обязательные элементы) **НЕ МОЖЕТ** быть изменено расширениями.

### 7.2. Допустимые расширения

#### 7.2.1. Наследование через xs:extension

```xml
<!-- Допустимо -->
<xs:complexType name="ExtendedComponentType">
  <xs:complexContent>
    <xs:extension base="eskd-ekb:AllowedComponentItemType">
      <xs:sequence>
        <xs:element name="industrySpecific" minOccurs="0"/>
      </xs:sequence>
    </xs:extension>
  </xs:complexContent>
</xs:complexType>
```

#### 7.2.2. Дополнительные атрибуты через xs:any

```xml
<xs:complexType name="ProfileExtensionType">
  <xs:sequence>
    <xs:any namespace="##other" processContents="lax" 
            minOccurs="0" maxOccurs="unbounded"/>
  </xs:sequence>
</xs:complexType>
```

#### 7.2.3. Отдельный namespace для расширений

```
Ядро:     http://gost.ru/eskd/profile/ekb/2024
Расширение: http://gost.ru/eskd/profile/ekb/2024/extension/{industry}
```

### 7.3. Недопустимые действия

| Действие | Статус | Обоснование |
|----------|--------|-------------|
| Изменение обязательности атрибутов ядра | ❌ Запрещено | Нарушает контракт профиля |
| Удаление элементов ядра | ❌ Запрещено | Нарушает семантику профиля |
| Изменение типов данных ядра | ❌ Запрещено | Нарушает валидацию |
| Переопределение элементов через restriction | ❌ Запрещено | Нарушает наследование |

### 7.4. Регистрация расширений

1. Создать отдельный XSD-файл расширения
2. Импортировать ядро профиля
3. Использовать уникальный namespace
4. Документировать правила применения

## 8. Проверка соответствия

### 8.1. Минимальный набор тестов

| Тест | Описание | Уровень | Критерий |
|------|----------|---------|----------|
| **Тест 1** | Структурная валидация (XSD) | A (Базовый) | 0 ошибок XSD |
| **Тест 2** | Обязательные атрибуты | A (Базовый) | 100% mandatory заполнены |
| **Тест 3** | Ссылочная целостность (Schematron) | B (Расширенный) | 0 broken references |
| **Тест 4** | Бизнес-правила (Schematron) | B (Расширенный) | Все date-правила пройдены |
| **Тест 5** | Маппинг 2.525 ↔ 2.058 | C (Полный) | 100% ссылок валидны |

### 8.2. Протокол тестирования

| Поле | Значение |
|------|----------|
| Идентификатор теста | {PROFILE}-{TEST}-{NNN} |
| Дата проведения | YYYY-MM-DD |
| Результат | PASS / FAIL |
| Степень интероперабельности | 0.00 - 1.00 |
| Подписант | Организация / Лицо |

### 8.3. Инструменты валидации

| Инструмент | Назначение | Требования |
|------------|------------|------------|
| XML валидатор | Проверка XSD | Поддержка XSD 1.1 |
| Schematron процессор | Проверка бизнес-правил | XSLT 2.0+ |
| XPath процессор | Проверка ссылок | XPath 2.0+ |
