# ИЗМЕНЕНИЯ ПО ШАГУ 2.3: КЛАССИФИКАЦИЯ ДОКУМЕНТОВ (ГОСТ 2.102-2023)

## Обзор изменений

В рамках шага 2.3 реализована поддержка классификации конструкторских документов в соответствии с ГОСТ 2.102-2023. Основные изменения:

1. **Создан новый модуль** `eskd_document_classification.xsd` с кодами видов документов
2. **Обновлён профиль** `eskd_profile_ekb.xsd` с добавлением ссылок на ведомости
3. **Обновлён модуль проверки** `eskd_compliance_check.xsd` с поддержкой ЭСК

---

## 1. Новый файл: `xsd/modules/eskd_document_classification.xsd`

**Пространство имён:** `http://gost.ru/eskd/docclass/2024`  
**Префикс:** `eskd-dc`

### Определённые типы:

#### `DocumentKindCodeEnum` (простой тип)
Перечень кодов видов документов по таблице 1 ГОСТ 2.102-2023:

| Код | Наименование | Описание |
|-----|--------------|----------|
| `СП` | Спецификация | Текстовый документ, определяющий состав сборочной единицы |
| `ЭСК` | Электронная конструктивная структура | Электронный документ, аналог спецификации |
| `ВП` | Ведомость покупных изделий | Перечень покупных изделий в составе |
| `ВР` | Ведомость разрешения применения | Документ о допустимости применения |
| `ПЭ3` | Перечень элементов | Для электрических схем |
| `ТУ` | Технические условия | Требования к изделию |
| `СБ` | Сборочный чертеж | Чертеж сборочной единицы |
| `Ч` | Чертеж детали | Рабочий чертеж детали |
| `Д` | Документ | Общий случай |
| `ПМ` | Программа и методика испытаний | Документ для испытаний |
| `ВО` | Ведомость содержания драгматериалов | - |
| `ВМ` | Ведомость монтажных соединений | - |
| `ПЛУ` | Перечень условий | - |
| `ГЧ` | Габаритный чертеж | - |
| `МЧ` | Монтажный чертеж | - |
| `ПС` | Паспорт | - |
| `РЭ` | Руководство по эксплуатации | - |
| `ИМ` | Инструкция по монтажу | - |
| `ФО` | Формуляр | - |
| `ЭО` | Ведомость эксплуатационных документов | - |

#### `StructureDocumentType` (комплексный тип, абстрактный)
Базовый тип для документов, определяющих структуру изделия:
- Наследует от `eskd-core:BaseEntityType`
- Содержит элементы: `documentKind`, `designation`, `name`
- Предназначен для использования через ссылки (IDREF)
- Поддерживает как СП, так и ЭСК

## 2. Изменения в `xsd/profile/eskd_profile_ekb.xsd`

### 2.1. Добавлен импорт нового модуля

**Строки 8, 25-26:**
```xml
xmlns:eskd-dc="http://gost.ru/eskd/docclass/2024"
...
<xs:import namespace="http://gost.ru/eskd/docclass/2024"
           schemaLocation="../modules/eskd_document_classification.xsd"/>
```

### 2.2. Расширен `AllowedComponentListType`

**Добавлены элементы после `allowedItems` (строки 255-287):**

```xml
<!-- Расширение по ГОСТ 2.102-2023: связь с ведомостями -->
<xs:element name="purchasedItemsListRef" type="xs:IDREF" minOccurs="0" maxOccurs="1">
  <xs:annotation>
    <xs:documentation>
      Ссылка на ведомость покупных изделий (ВП).
      
      Согласно ГОСТ 2.102-2023 (п. 5.3.4), ведомость покупных изделий
      содержит перечень всех покупных изделий, применяемых в составе изделия.
      
      Данный элемент обеспечивает связь между разрешённым перечнем ЭКБ/РЭА
      и конструкторским документом типа "Ведомость покупных изделий" (код ВП).
      
      Целевой объект должен иметь documentKind = "ВП".
    </xs:documentation>
  </xs:annotation>
</xs:element>

<xs:element name="permissionListRef" type="xs:IDREF" minOccurs="0" maxOccurs="1">
  <xs:annotation>
    <xs:documentation>
      Ссылка на ведомость разрешения применения покупных изделий (ВР).
      
      Согласно ГОСТ 2.102-2023 (п. 5.3.5) и ГОСТ 2.124-2014,
      ведомость разрешения применения фиксирует решение о допустимости
      применения конкретных покупных изделий в данном изделии.
      
      Данный элемент обеспечивает трассируемость между разрешённым перечнем
      и документом, утверждающим применение конкретных позиций.
      
      Целевой объект должен иметь documentKind = "ВР".
    </xs:documentation>
  </xs:annotation>
</xs:element>
```

### 2.3. Расширен `AllowedComponentItemType`

**Добавлен элемент после `approvalHistory` (строки 419-437):**

```xml
<!-- Расширение по ГОСТ 2.102-2023: связь с ведомостью разрешения применения -->
<xs:element name="permissionDocumentRef" type="xs:IDREF" minOccurs="0" maxOccurs="1">
  <xs:annotation>
    <xs:documentation>
      Ссылка на документ "Ведомость разрешения применения" (ВР) для данной позиции.
      
      Согласно ГОСТ 2.102-2023 (п. 5.3.5), ведомость разрешения применения
      фиксирует решение о допустимости применения конкретного покупного изделия
      в данном изделии.
      
      Данный элемент обеспечивает трассируемость между позицией разрешённого перечня
      и конкретным документом, утверждающим применение этого компонента.
      
      Целевой объект должен иметь documentKind = "ВР".
      Отличается от permissionListRef тем, что ссылается на документ уровня позиции,
      а не всего перечня.
    </xs:documentation>
  </xs:annotation>
</xs:element>
```

## 3. Изменения в `xsd/modules/eskd_compliance_check.xsd`

### 3.1. Добавлен импорт модуля классификации

```xml
           schemaLocation="eskd_document_classification.xsd"/>
```

### 3.2. Обновлена документация для `productRef`

**Строки 360-383:**
Расширена документация элемента `productRef` в `ComplianceReportType`:

```xml
<xs:element name="productRef" type="xs:IDREF" minOccurs="1" maxOccurs="1">
  <xs:annotation>
    <xs:documentation>
      Ссылка на проверяемое изделие (обязательно).
      
      Ссылается на:
      - eskd_product из ГОСТ Р 2.525-2024
      - ИЛИ на документ типа "Электронная конструктивная структура" (ЭСК)
        из ГОСТ 2.102-2023
      
      Изделие, состав ЭКБ/РЭА которого проверяется на 
      соответствие разрешённому перечню.
      
      Согласно ГОСТ 2.053-2023 (пункт 5.1), продукт является 
      корневым объектом электронной структуры изделия.
      
      Согласно ГОСТ 2.102-2023 (пункт 5.2.1.1), электронная 
      конструктивная структура (ЭСК) может выполнять функцию 
      основного конструкторского документа наравне со спецификацией.
      Поэтому productRef может ссылаться как на продукт в смысле 
      2.525, так и на документ ЭСК.
    </xs:documentation>
  </xs:annotation>
</xs:element>
```

## 4. Обратная совместимость

Все новые элементы являются **опциональными** (`minOccurs="0"`):
- `purchasedItemsListRef` — опционально
- `permissionListRef` — опционально
- `permissionDocumentRef` — опционально

Существующие XML-документы остаются валидными без изменений.

## 5. Соответствие ГОСТ

### ГОСТ 2.102-2023
- **Таблица 1**: Полный перечень кодов видов документов
- **Пункт 5.2.1**: Спецификация как основной документ сборочной единицы
- **Пункт 5.2.1.1**: ЭСК как альтернатива спецификации
- **Пункт 5.3.4**: Ведомость покупных изделий (ВП)
- **Пункт 5.3.5**: Ведомость разрешения применения (ВР)

### ГОСТ 2.053-2023
- **Пункт 5.1**: Продукт как корневой объект электронной структуры
- **Пункт 5.2.1.1**: Поддержка ЭСК

### ГОСТ 2.124-2014
- **Порядок применения покупных изделий**: Трассируемость через ВР

## 6. Пример использования

```xml
<?xml version="1.0" encoding="UTF-8"?>
<eskd-ekb:allowed_component_list 
    xmlns:eskd-ekb="http://gost.ru/eskd/profile/ekb/2024"
    xmlns:eskd-dc="http://gost.ru/eskd/docclass/2024"
    id="ACL-001">
    
  <listId>ПЛ-ЭКБ-2024-001</listId>
  <listName>Разрешённый перечень ЭКБ</listName>
  
  <!-- Ссылка на ведомость покупных изделий -->
  <purchasedItemsListRef ref="#VP-001"/>
  
  <!-- Ссылка на ведомость разрешения применения -->
  <permissionListRef ref="#VR-001"/>
  
  <allowedItems>
    <allowedItem id="ITEM-001">
      <itemId>POS-001</itemId>
      <componentRef ref="#COMP-001"/>
      <approvalStatus>approved</approvalStatus>
      
      <!-- Ссылка на ВР для конкретной позиции -->
      <permissionDocumentRef ref="#VR-001-POS-001"/>
    </allowedItem>
  </allowedItems>
</eskd-ekb:allowed_component_list>

<!-- Документ ВП (пример) -->
<document id="VP-001">
  <documentKind>ВП</documentKind>
  <designation>АБВГ.123456.001 ВП</designation>
  <name>Ведомость покупных изделий</name>
</document>

<!-- Документ ВР (пример) -->
<document id="VR-001">
  <documentKind>ВР</documentKind>
  <designation>АБВГ.123456.001 ВР</designation>
  <name>Ведомость разрешения применения</name>
</document>
```

## 7. Инструкция по подключению

### Для новых проектов:
1. Убедиться, что все три модуля доступны:
   - `xsd/modules/eskd_document_classification.xsd`
   - `xsd/profile/eskd_profile_ekb.xsd`
   - `xsd/modules/eskd_compliance_check.xsd`

2. Использовать пространства имён:
   ```xml
   xmlns:eskd-dc="http://gost.ru/eskd/docclass/2024"
   xmlns:eskd-ekb="http://gost.ru/eskd/profile/ekb/2024"
   xmlns:eskd-cc="http://gost.ru/eskd/compliance/2024"
   ```

### Для существующих проектов:
1. Добавить импорт в головную схему (если используется кастомная сборка):
   ```xml
   <xs:import namespace="http://gost.ru/eskd/docclass/2024"
              schemaLocation="modules/eskd_document_classification.xsd"/>
   ```

2. Существующие документы не требуют изменений (обратная совместимость).
