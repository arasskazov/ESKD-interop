 ## Нормативные источники

Ключевые поля:
 * `doc_id` — стабильный внутренний идентификатор.
 * `doc_code` — официальное обозначение документа.
 * `title` - Название ГОСТ
 * `status_rf` — фактический статус для использования в РФ.
 * `replaces` / `replaced_by` — связи замены.
 * `source_url` — источник проверки статуса.
 * `file_path` / `text_path` — где лежат PDF и извлеченный текст.
 * `authority_level` — official, reference, internal.
